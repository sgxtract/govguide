# GovGuide — Government Guide for the Sorsoganons

An independent, citizen-friendly guide to getting government services done in Sorsogon: where to go, what to bring, the steps, fees, and processing time. Every guide links to its official source.

> Not an official government website.

## Run locally

Requires Node 24 (`.nvmrc`) and pnpm.

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm check      # lint + typecheck + format check
```

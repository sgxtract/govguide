# 0002 — Independent community guide

- Status: Accepted
- Date: 2026-10-19

## Decision

GovGuide is an independent guide, not an official LGU website. It uses no official seals or logos, and every page links to official sources. A clear disclaimer is shown site-wide. Repo and hosting live on the maintainer's personal accounts (sgxtract) and can be transferred to an organization later.

## Consequences

- We can move fast without an approval chain, but trust has to be earned through sources and "Last verified" dates.
- If the LGU adopts it later, revisit branding, domain, and content sign-off in a new ADR.

# Lesson 07 — Checklist & print

**Built:** real tick-box checklist (works without JS, ticks remembered per guide on the phone), "Print or save as PDF" button, print stylesheet (light palette, no screen chrome, link addresses, no split items, print-only header line).

**Remember:**

- Ticks are matched by requirement label: rewording a requirement clears its tick (on purpose).
- Test print with DevTools → Rendering → "Emulate CSS media type: print", or just print to PDF.
- Mark screen-only UI with `print:hidden`.
